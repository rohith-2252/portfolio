# Rohith R — Portfolio

A premium, animated personal portfolio built with React, Vite, Tailwind CSS v4, and Framer Motion.

## Getting started

```bash
npm install
npm run dev       # start local dev server
npm run build     # production build -> dist/
npm run preview   # preview the production build
```

## Notes

- Replace `public/resume.pdf` with your actual résumé (the Hero "Download Resume" button links to `/resume.pdf`).
- Swap `src/assets/profile.png` for a higher-resolution photo if you have one.
- All content (roles, stats, education, skills, services, projects, achievements, contact info) lives in `src/data.js` — edit it there to update the site.
- The interactive dot-network background is a canvas component in `src/components/NetworkBackground.jsx`.
